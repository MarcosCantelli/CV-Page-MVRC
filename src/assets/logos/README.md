# Company logos

Drop the logo files here (SVG, PNG, JPG, WebP or AVIF). The file name must match the
`logo` field in `src/content/cv.*.ts`:

| File                     | Company         |
| ------------------------ | --------------- |
| `bradesco.svg` / `.png`  | Bradesco        |
| `jovem-pan.svg` / `.png` | Rádio Jovem Pan |

Raster images are converted to AVIF/WebP at build time. While a file is missing, the
timeline shows the company initials instead.
