# Certification badges

Drop the official badge images here (SVG, PNG, JPG, WebP or AVIF). The file name must
match the `badge` field in `src/content/cv.*.ts`:

| File                    | Certification                         |
| ----------------------- | ------------------------------------- |
| `az-900.png`            | Microsoft Azure Fundamentals (AZ-900) |
| `ccna-itn.png`          | Cisco CCNA – Introduction to Networks |
| `az-104.png` (optional) | Azure Administrator (in preparation)  |

Raster images are converted to AVIF/WebP at build time. While a file is missing, the
card shows an icon instead.
